# Jaijitesh Suryaprakash — Systems & Robotics Portfolio

> **Editorial, minimal, typography-led portfolio of Jaijitesh Suryaprakash (Berry).**

## 🏛️ Design & Engineering Architecture

- **Editorial Typography**: Grotesque headings (`Plus Jakarta Sans`), curated serif accents (`Newsreader`), and monospace data labels (`JetBrains Mono`).
- **Deep Obsidian Palette**: Harmonious dark theme (`#090a0c`) accented with warm amber/gold (`#e5a93c`), rejecting generic neon AI tropes.
- **Featured Systems & Verified Work**:
  - **WindSim**: Deterministic Lattice Boltzmann Method (LBM D2Q9 / D3Q19) fluid dynamics simulator with real-time vector field streamlines and aerodynamic lift/drag estimation.
  - **AutoBot**: Differential-drive tracked robotics platform powered by an ESP32 microcontroller with closed-loop optical quadrature encoder PID regulation and web telemetry.
  - **Berry**: Autonomous desktop assistant with local LLM integration, persistent filesystem codices, and voice synthesis pipelines.
  - **Performance Monitor**: Hardware telemetry dashboard built with TypeScript, Electron, and WebSockets for real-time sensor metrics.
- **Interactive 3D Credential**: Custom Three.js lanyard simulation on `personal.html` with spring kinematics, Verlet curve integration, and `IntersectionObserver` pause-on-scroll optimization.
- **Honest Communications**: Direct one-click email copying, pre-formatted native mail client dispatch, and zero fake backend or visitor count claims.
- **Accessibility & Multi-Viewport**: Full `prefers-reduced-motion` compliance, visible focus states, semantic HTML5 tags, and responsive layouts verified from 390px mobile to 1440px desktop.

---

## 📂 Site Structure

- `index.html`: Main portfolio showcasing identity, verified projects, about, and milestone timeline.
- `personal.html`: Research archive, foundational computing literature, media inspirations, and 3D credential.
- `contact.html`: Direct transmission portal, honest dispatch form, availability status, and technical FAQ.
- `404.html`: Coherent not-found page with clear return navigation.
- `style.css`: Unified design system tokens, typography scales, components, and responsive media queries.
- `js/portfolioEngine.js`: Accessible interactive controller (toast feedback, clipboard copy, mobile drawer, dot globe).
- `js/eventBadge3D.js`: Three.js lanyard badge simulation with drag physics and viewport visibility observation.
