## ⚡ Features

- **Interactive 3D Spline Tubes Cursor**: Procedural glowing ribbon tubes tracking the cursor in real-time using Three.js shader pipelines.
- **Dynamic Palette Cycling**: Click anywhere on the viewport to cycle across curated neon palettes (Emerald/Cyan, Cyberpunk, Electric Blue/Pink, Sunset Amber, Hyper Violet).
- **Ultra-Lightweight & Instant Load**: Zero heavy assets, sub-second initial load, locked 60+ FPS on any hardware or integrated GPU.
- **Responsive Typography**: Built with Space Grotesk, Space Mono, and Inter with fluid viewport scaling (`clamp()`).
- **Archive Notice**: The full 3D Engineering Lab Bench & JAIJITESH.OS desktop environment is safely preserved in the `_saved_room_os_backup/` local directory.
