## 👋 About Me

Hey! I'm Jaijitesh, an undergraduate student studying **Information Technology at Vellore Institute of Technology (VIT Vellore)**. I go by **Berry** across GitHub and developer communities.

I like building at the intersection of hardware, mathematics, and software. My engineering focus is driven by first-principles thinking: understanding physical systems, control theory, and operating system mechanics from the ground up rather than leaning on black-box abstractions.

Whether I'm tuning 200Hz closed-loop PID velocity controllers on an ESP32 robot, solving fluid flow approximations in WebGL with the Lattice Boltzmann Method, or orchestrating local AI agent runtimes in Python, I care about clean architecture, deterministic execution, and tangible real-world results.

## 🚀 Featured Projects

Here are a few selected projects I've built and actively develop:

### 🌪️ [WindSim](https://github.com/BerrF35/Windsim)
**Browser-Native Computational Fluid Dynamics & Aerodynamics Sandbox**  
A client-side aerodynamic sandbox built with JavaScript and Three.js. Combines reduced-order flight physics with an interactive Lattice Boltzmann Method (LBM D2Q9 & D3Q19) solver, real-time 3D vector field streamlines, and live aerodynamic lift/drag estimation over airfoils (like NACA 0012).
- **Stack:** JavaScript, Three.js, WebGL, LBM CFD, Numerical Aerodynamics

### 🤖 [AutoBot](https://github.com/BerrF35/AutoBot)
**Autonomous Tracked Robotics Platform**  
An autonomous tracked ground robot powered by an ESP32 microcontroller running FreeRTOS. Features dual optical quadrature encoders (1024 CPR), 200Hz closed-loop PID velocity regulation with anti-windup, S-curve motion profiling, 6-DOF IMU attitude fusion, and a live web telemetry HUD.
- **Stack:** C++, ESP32-WROOM-32, FreeRTOS, PID Control, Optical Encoders, WebSockets

### 🍓 [Berry](https://github.com/BerrF35/Berry)
**Local-First Desktop AI Agent Runtime**  
An autonomous desktop assistant built in Python and FastAPI that connects language model reasoning directly to local operating system execution. Implements terminal execution sandboxing, file tree manipulation, persistent local vector codices, and low-latency neural voice synthesis.
- **Stack:** Python, FastAPI, Local Memory Embeddings, Tool Calling, Voice Synthesis

### 📈 [Performance-Monitor](https://github.com/BerrF35/Performance-Monitor)
**Real-Time Windows Hardware Telemetry Dashboard**  
A desktop hardware telemetry dashboard built with Electron, React, and TypeScript. Polls Windows WMI and low-level system APIs at 1000ms intervals to stream metrics for CPU, GPU, RAM, disk throughput, thermals, and active processes with industrial telemetry graphs.
- **Stack:** TypeScript, Electron, React, Tailwind CSS, Windows System APIs

### 🌾 FarmAssist AI
**Edge AI & IoT Diagnostics Platform — 3rd Place Overall at ImpactX 3.0 Hackathon**  
Engineered the edge inference and backend communication layer on Raspberry Pi hardware, coordinating real-time WebSocket telemetry and edge diagnostic models for agricultural monitoring.
